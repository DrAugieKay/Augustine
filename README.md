## Deploy as `username.github.io`
1. Create repo named exactly `<your-username>.github.io`.
2. Upload all files (keep structure: `index.html` at root, `css/`, `js/`, `assets/`).
3. Settings → Pages → Deploy from branch → `main` / root → Save.
4. Live at `https://<your-username>.github.io/` within ~1 min. Both `/` (EN) and `/zh.html` (中文) work.
